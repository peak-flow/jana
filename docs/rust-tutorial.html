Rust Features Used in Jana

async/await with Tokio

All database and HTTP operations are async. Tokio runtime handles concurrency without blocking the UI thread.

pub async fn create_note() -> Result<Note>

Result<T, E> Error Handling

No exceptions! Explicit error handling with Result and the ? operator for propagation.

.await.map_err(|e| e.to_string())?;

Derive Macros

Auto-generate implementations for serialization, cloning, and debugging.

#[derive(Serialize, Deserialize, Clone)]
pub struct Note { ... }

State Management

Tauri injects shared state (like DB pool) into commands automatically.

state: State<'_, DbState>

sqlx Compile-Time Checks

SQL queries can be verified at compile time. Runtime uses type-safe bindings.

sqlx::query("SELECT * FROM notes")
    .bind(&id)

Option<T> for Nullability

No null pointer exceptions. Optional values are explicit with Option<T>.

pub title: Option<String>

UUID Generation

Generate unique IDs with the uuid crate. No database auto-increment needed.

Uuid::new_v4().to_string()

reqwest HTTP Client

Async HTTP client for calling external APIs (like LM Studio).

client.post(&url).json(&req).send().await

Side-by-side: How you'd write it in Laravel vs Rust/Tauri

Creating a Note

Laravel PHP 
// app/Http/Controllers/NoteController.php

class NoteController extends Controller
{
    public function store(Request $request)
    {
        $note = Note::create([
            'id' => Str::uuid(),
            'title' => null,
            'content' => null,
        ]);

        return response()->json($note);
    }
}
Rust / Tauri 
// src-tauri/src/commands/notes.rs

#[tauri::command]
pub async fn create_note(
    state: State<'_, DbState>
) -> Result<Note, String> {
    let now = chrono::Utc::now().timestamp();
    let note = Note {
        id: Uuid::new_v4().to_string(),
        title: None,
        content: None,
        created_at: now,
        updated_at: now,
    };

    sqlx::query("INSERT INTO notes ...")
        .bind(¬e.id)
        .execute(&state.pool)
        .await
        .map_err(|e| e.to_string())?;

    Ok(note)
}

HTTP API Call (LLM Summarization)

Laravel PHP (Guzzle) 
// Using Laravel HTTP client

use Illuminate\Support\Facades\Http;

$response = Http::timeout(60)
    ->post($llmUrl, [
        'model' => $model,
        'messages' => [
            ['role' => 'system', 'content' => $prompt],
            ['role' => 'user', 'content' => $content],
        ],
        'temperature' => 0.3,
    ]);

$summary = $response->json('choices.0.message.content');
Rust (reqwest) 
// Using reqwest async client

let client = reqwest::Client::builder()
    .timeout(Duration::from_secs(60))
    .build()?;

let response = client
    .post(&llm_url)
    .json(&OpenAIRequest {
        model: llm_model,
        messages: vec![...],
        temperature: 0.3,
    })
    .send().await?
    .json::<OpenAIResponse>().await?;

let summary = response.choices
    .first()
    .map(|c| c.message.content.clone());

Key Differences Summary

Aspect Laravel / PHP Rust / Tauri
Error Handling Exceptions (try/catch) Result<T, E> + ? operator
Null Safety Nullable types, runtime errors Option<T>, compile-time checks
Async Queues, optional async Native async/await, Tokio
Database Eloquent ORM sqlx (raw SQL, type-safe)
Memory Garbage collected Ownership system, no GC
Compilation Interpreted (JIT) Compiled to native binary
Type System Dynamic (with type hints) Static, strict
Package Manager Composer Cargo
